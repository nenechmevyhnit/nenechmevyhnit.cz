# Oblasti: plán implementace

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Výchozí pohled přehledu `/pravidla/` se změnami pravidel seskupenými do osmi oblastí státu. U každé změny je text „Co by to znamenalo pro vás“, u oblasti úvod „K čemu to je“ a citace „Jak to hodnotí“. Test kontroly moci se rozšiřuje o další instituce a pravidla státu.

**Architecture:** Statický web v Astru. Obsah je v Markdownu s YAML frontmatterem, validuje se zodem v `src/lib/` a načítá přes `overAdresar` → `src/lib/kauzy.ts`. Oblasti mají uzavřený slovník v `pravidla-slovnik.ts`, změna pravidla nese pole `oblasti` a `proVas`, každá oblast má soubor `obsah/oblasti/<id>.md` (úvod, hodnocení, zdroje). Odvozené hodnoty (počty, řazení, „bez připomínkového řízení“) počítá `src/lib/oblasti.ts`. Detail oblasti je statická stránka `/pravidla/oblasti/<id>/`, kterou přehled otevírá do stejného `<dialog id="detail">` jako detail pravidla.

**Tech Stack:** Astro 7, TypeScript, zod (`astro/zod`), gray-matter, vitest 5, Playwright 1.65.

**Spec:** `docs/superpowers/specs/2026-11-13-oblasti-design.md`. Navazuje na `2026-11-13-zmeny-pravidel-design.md`, `2026-11-13-kontrola-moci-design.md` a `2026-11-13-osa-pravidel-design.md`.

## Global Constraints

- Jazyk všech textů je čeština se správnou diakritikou. Identifikátory v kódu jsou česky bez diakritiky, stejně jako ve zbytku repozitáře.
- Ve vlastním textu archivu (popisky, Metodika, texty v UI) se nepoužívají výrazy „ušité“, „na míru“, „ohýbání“ ani „oslabení“. Popisky oblastí nepojmenovávají vládu, Babiše ani Agrofert.
- Barva nehodnotí. Červená `#DB1F2D` se smí objevit jen v nadtitulku (třída `u2-nad`).
- Žádné svislé posouvání stránky na velikostech `VELIKOSTI` z `tests/e2e/pomocne.ts`. Delší obsah se posouvá uvnitř panelu (sloupce do strany jako u záložky Zdroje).
- `proVas.text` a `uvod.text` mají nejvýš 400 znaků, `citace` nejvýš 500.
- Počty na kartě a v hlavičce oblasti: `N změn · N přijato · N v projednávání`, a ` · N ukončeno` jen když je nenulové. „Přijato“ = poslední krok `vyhlaseno` nebo `schvaleno`, „ukončeno“ = krok z `UKONCUJICI`, ostatní = „v projednávání“. (Spec říká „schváleno nebo platí“, „přijato“ zahrnuje obojí, včetně schváleného usnesení vlády.)
- Adresy pohledů: Oblasti `/pravidla/` (výchozí, pokud existuje aspoň jedna karta), Seznam `/pravidla/?pohled=seznam`, Časová osa `/pravidla/?pohled=osa`. Když žádná karta není, výchozí je Seznam a má adresu `/pravidla/`.
- Klíč detailu v navigaci: slug pravidla, nebo `oblasti/<id>` u oblasti. Adresa detailu je vždy `/pravidla/<klíč>/`. Slug pravidla `oblasti` je zakázaný.
- Filtr „bez připomínkového řízení“ je přepínací čip `[data-bez-pripominek]` v řádku čipů (spec píše „zaškrtávátko“. Čip funguje stejně a nerozbije řádek filtrů na mobilu).
- `_koncepty/` (mimo git, sdílené všemi větvemi) se v tomto plánu needituje.
- Commity jsou česky a končí řádkem `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

```ts
import { z } from 'astro/zod';
import { datum, datumPresne, text, odkazy, idTvar, zdrojSchema } from './schema';
import { TYPY_HODNOCENI } from './pravidla-slovnik';

/** Citace v „Jak to hodnotí“ (specifikace oblastí, oddíl 5 a 7.2). */
const hodnoceniSchema = z.object({
  typ: z.enum(TYPY_HODNOCENI),
  kdo: text(),
  funkce: text().optional(),
  citace: text().max(500, 'Citace smí mít nejvýš 500 znaků'),
  datum,
  zdroje: odkazy('Hodnocení'),
  /** Slugy změn v této oblasti, ke kterým se citace vztahuje. */
  pravidla: z.array(idTvar).default([]),
}).strict();

/** koncepty = true: lokální náhled, smí chybět datum ověření. */
const vytvorOblastSchema = (koncepty: boolean) => z
  .object({
    uvod: z.object({ text: text().max(400, 'Úvod oblasti smí mít nejvýš 400 znaků'), zdroje: odkazy('Úvod oblasti') }).strict(),
    hodnoceni: z.array(hodnoceniSchema).default([]),
    zdroje: z.array(zdrojSchema).min(1, 'Oblast musí mít aspoň jeden zdroj'),
    overeno: koncepty ? datumPresne.nullable().default(null) : datumPresne,
  })
  .strict()
  .superRefine((o, ctx) => {
    const chyba = (message: string) => ctx.addIssue({ code: 'custom', message });
    const ids = new Set<number>();
    for (const zd of o.zdroje) {
      if (ids.has(zd.id)) chyba(`Duplicitní id zdroje ${zd.id}`);
      ids.add(zd.id);
    }
    const over = (cisla: number[], kde: string) => {
      for (const c of cisla) if (!ids.has(c)) chyba(`${kde} odkazuje na neexistující zdroj ${c}`);
    };
    over(o.uvod.zdroje, 'Úvod oblasti');
    o.hodnoceni.forEach((h, i) => {
      over(h.zdroje, `Hodnocení ${i + 1} („${h.kdo}“)`);
      if ((h.typ === 'vlada' || h.typ === 'odbornik') && !h.funkce) chyba(`Hodnocení ${i + 1} („${h.kdo}“) musí uvést funkci (funkce)`);
    });
    if (o.hodnoceni.length > 0 && !o.hodnoceni.some(h => h.typ === 'vlada'))
      chyba('Oblast s hodnoceními musí mít aspoň jedno stanovisko vlády (typ: vlada); když vláda nereagovala, citujte účel z důvodové zprávy');
  });

export const oblastSchema = vytvorOblastSchema(false);
export const oblastSchemaKoncepty = vytvorOblastSchema(true);
export type OblastData = z.infer<typeof oblastSchemaKoncepty>;
export type Hodnoceni = OblastData['hodnoceni'][number];
```

```ts
import { oblastSchema, oblastSchemaKoncepty, type OblastData } from './schema-oblasti';
```

- za typ `PravidloZaznam` přidat `export type OblastZaznam = { id: Oblast; data: OblastData };`
- před `type SouborObsahu` přidat funkci:

```ts
/** Soubory oblastí (specifikace oblastí, oddíl 7.2 a 7.3). Oblast s aspoň jednou změnou musí mít soubor s úvodem.
 *  Odkaz hodnocení na neexistující změnu veřejný build vynechá s varováním (změna může být zatím jen v konceptech),
 *  odkaz na změnu z jiné oblasti je vždy chyba. */
export function overOblasti(adresar: string, soubory: { slug: string; soubor: string; data: unknown }[], pravidla: PravidloZaznam[], rezim: Rezim = {}): { oblasti: OblastZaznam[]; chyby: Chyba[]; varovani: Chyba[] } {
  const chyby: Chyba[] = [];
  const varovani: Chyba[] = [];
  const nactene = new Map<Oblast, OblastData>();
  const schema = rezim.koncepty ? oblastSchemaKoncepty : oblastSchema;
  for (const s of soubory) {
    if (!(OBLASTI as readonly string[]).includes(s.slug)) { chyby.push({ soubor: s.soubor, zprava: `Neznámá oblast „${s.slug}“ (oblasti jsou ve slovníku src/lib/pravidla-slovnik.ts)` }); continue; }
    const r = schema.safeParse(s.data);
    if (!r.success) { for (const i of r.error.issues) chyby.push({ soubor: s.soubor, zprava: `${i.path.join('.') || 'oblast'}: ${i.message}` }); continue; }
    const id = s.slug as Oblast;
    const hodnoceni = r.data.hodnoceni.map((h, i) => ({
      ...h,
      pravidla: h.pravidla.filter(slug => {
        const z = pravidla.find(p => p.slug === slug);
        const kde = `Hodnocení ${i + 1} („${h.kdo}“)`;
        if (!z) {
          const zprava = `${kde} odkazuje na neexistující změnu „${slug}“`;
          if (rezim.koncepty) chyby.push({ soubor: s.soubor, zprava });
          else varovani.push({ soubor: s.soubor, zprava: `${zprava} (odkaz se nezobrazí)` });
          return false;
        }
        if (!z.pravidlo.oblasti?.includes(id)) { chyby.push({ soubor: s.soubor, zprava: `${kde} odkazuje na změnu „${slug}“, která do oblasti nepatří` }); return false; }
        return true;
      }),
    }));
    nactene.set(id, { ...r.data, hodnoceni });
  }
  for (const z of pravidla) {
    const soubor = join(adresar, 'pravidla', `${z.slug}.md`);
    if (rezim.koncepty && !z.pravidlo.oblasti) varovani.push({ soubor, zprava: 'Změna zatím nemá oblasti (v pohledu Oblasti se nezobrazí)' });
    if (rezim.koncepty && !z.pravidlo.proVas) varovani.push({ soubor, zprava: 'Změna zatím nemá text „Co by to znamenalo pro vás“' });
  }
  for (const id of OBLASTI) {
    if (nactene.has(id) || !pravidla.some(z => z.pravidlo.oblasti?.includes(id))) continue;
    const soubor = join(adresar, 'oblasti', `${id}.md`);
    const zprava = `Oblast „${id}“ má zveřejněné změny, ale chybí soubor ${soubor} s úvodem`;
    if (rezim.koncepty) varovani.push({ soubor, zprava });
    else chyby.push({ soubor, zprava });
  }
```

```ts
import { sklonuj } from './cestina';
import { UKONCUJICI, stavPravidla, type Krok } from './pravidla-stavy';
import { vynechaneKontroly, OBLASTI, oblast as popisOblasti, TYPY_HODNOCENI, popisekTypuHodnoceni, type Cesta, type Oblast, type TypHodnoceni } from './pravidla-slovnik';
import { seraditPravidla } from './pravidla';
import type { PravidloZaznam, OblastZaznam } from './validace';
import type { Hodnoceni, OblastData } from './schema-oblasti';

/** Odvozené hodnoty pohledu Oblasti (specifikace oblastí, oddíl 7.3). Nikam se nezapisují. Část se používá i v prohlížeči. */
export type KategorieStavu = 'prijato' | 'projednava' | 'ukonceno';
export const kategorieStavu = (k: Krok): KategorieStavu =>
  UKONCUJICI.includes(k) ? 'ukonceno' : k === 'vyhlaseno' || k === 'schvaleno' ? 'prijato' : 'projednava';

export type Pocty = { celkem: number; prijato: number; projednava: number; ukonceno: number };
export function spocitej(kategorie: readonly KategorieStavu[]): Pocty {
  const p: Pocty = { celkem: kategorie.length, prijato: 0, projednava: 0, ukonceno: 0 };
  for (const k of kategorie) p[k]++;
  return p;
}
/** „3 změny · 1 přijata · 2 v projednávání“; ukončené jen tehdy, když nějaké jsou. */
export function textPoctu(p: Pocty): string {
  return [
    sklonuj(p.celkem, ['změna', 'změny', 'změn']),
    sklonuj(p.prijato, ['přijata', 'přijaty', 'přijato']),
    `${p.projednava} v projednávání`,
    ...(p.ukonceno > 0 ? [sklonuj(p.ukonceno, ['ukončena', 'ukončeny', 'ukončeno'])] : []),
  ].join(' · ');
}

/** Cesta předložení vynechává meziresortní připomínkové řízení (popis procesu, ne hodnocení). */
export const bezPripominek = (c: Cesta): boolean => vynechaneKontroly(c).length > 0;

export type OblastDetail = { id: Oblast; nazev: string; popisek: string; data: OblastData | null; zmeny: PravidloZaznam[]; pocty: Pocty };
/** Oblasti, do kterých patří aspoň jedna změna, v pořadí slovníku. data = null jen v náhledu konceptů. */
export function sestavOblasti(pravidla: PravidloZaznam[], soubory: OblastZaznam[]): OblastDetail[] {
  const data = new Map(soubory.map(s => [s.id, s.data]));
  return OBLASTI.flatMap(id => {
    const zmeny = seraditPravidla(pravidla.filter(z => z.pravidlo.oblasti?.includes(id)));
    if (zmeny.length === 0) return [];
    const { nazev, popisek } = popisOblasti(id);
    const pocty = spocitej(zmeny.map(z => kategorieStavu(stavPravidla(z.pravidlo.udalosti))));
    return [{ id, nazev, popisek, data: data.get(id) ?? null, zmeny, pocty }];
  });
}

export type SkupinaHodnoceni = { typ: TypHodnoceni; nazev: string; polozky: Hodnoceni[] };
export function skupinyHodnoceni(hodnoceni: readonly Hodnoceni[]): SkupinaHodnoceni[] {
  return TYPY_HODNOCENI
    .map(typ => ({ typ, nazev: popisekTypuHodnoceni(typ), polozky: hodnoceni.filter(h => h.typ === typ).sort((a, b) => b.datum.localeCompare(a.datum)) }))
    .filter(s => s.polozky.length > 0);
}
```

```ts
export type Pohled = 'oblasti' | 'seznam' | 'osa';

const maOblasti = (): boolean => document.querySelector('[data-oblasti-pohled]') !== null;
export const vychoziPohled = (): Pohled => (maOblasti() ? 'oblasti' : 'seznam');
export const aktualniPohled = (): Pohled => (document.body.dataset.pohledPravidel as Pohled | undefined) ?? vychoziPohled();
export function pohledZAdresy(): Pohled {

  if (p === 'osa' || p === 'seznam') return p;

  return vychoziPohled();
```

```ts
    }
    const zpet = adresaPohledu(pohled);
    if (!zaviramZHistorie && location.pathname + location.search !== zpet) history.pushState({}, '', zpet);
    zaviramZHistorie = false;
    vyber(null);
  });
  dlg.addEventListener('click', e => {
    if (e.target === dlg || (e.target as HTMLElement).closest('.zavrit')) dlg.close();
  });

  addEventListener('popstate', e => {
    const stav = e.state as { klic?: string; udalost?: number } | null;
    nastavPohledPravidel(pohledZAdresy());
    if (stav?.klic) { otevri(stav.klic, { pridatDoHistorie: false, udalost: stav.udalost }); return; }
```
